Software engineering case study

ClashUp

A multiplayer Minecraft game server with custom combat, game-state management, and autonomous units that navigate a changing 3D environment.

Project
Multiplayer game server
Technologies
Java, Paper API
Core systems
A* pathfinding, combat, game state

The engineering challenge

ClashUp brings custom units and combat rules into Minecraft. Unlike movement on a fixed grid, units must operate inside a live multiplayer world where terrain and obstacles affect every route.

The server coordinates custom combat, autonomous behavior, and game-state transitions while responding to multiple players in real time.

Autonomous movement

Units use A* pathfinding with obstacle-aware movement to choose routes through the game world. The implementation combines path planning with the server’s movement and combat systems so autonomous units can pursue objectives without relying on manually scripted paths.

  • Java server development using the Paper API.
  • Custom combat and multiplayer game-state management.
  • A* route selection for autonomous units.
  • Movement behavior that accounts for obstacles in the world.
